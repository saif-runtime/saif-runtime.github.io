Saif is a purpose-built runtime that plays your own copy of GTA: San Andreas on Apple Silicon. No Wine, no CrossOver, no virtual machine, no paid software.

What it is

The original game is a 32-bit Windows program, which a Mac can't run directly. Instead of emulating all of Windows, Saif re-implements just what the game needs, and runs it natively.

⚡

Custom ARM64 JIT

The game's x86 code is translated to native Apple Silicon machine code.

🎨

Metal graphics

Direct3D 9 is implemented directly on Metal.

🔊

Native audio & input

DirectSound, DirectInput etc. are handled with CoreAudio/SDL.

Why it exists

GTA: San Andreas was released in 2004. More than two decades later, there was still no proper macOS support and this frustrated me. The usual workarounds are often behind a paid app or a virtual machine, e.g. Wine, CrossOver, Parallels Desktop, Sikarugir and more. Some of them work (sort of), but they are clumsy to set up and do not provide native performance.

Why use the Saif runtime?
✓Tuned for GTA:SA, so the CPU and GPU paths are optimised directly
✓Free: no subscriptions, no Windows licence, no VM to configure
✓Lightweight app with a simple launcher: pick your game folder, press Launch
✓Widescreen, ultrawide and borderless fullscreen supported

Saif ships no game files and no Rockstar content. You bring your own copy of the game.

Frequently asked questions

What are the system requirements?
MacApple Silicon (M1 or newer). Intel Macs are unfortunately not supported.
macOSmacOS 13 Ventura or later
GameA complete Windows install of GTA: San Andreas v1.0 US (gta_sa.exe, 14,383,616 bytes). Other versions (Steam, Rockstar Launcher, Definitive Edition, v1.01) are not confirmed to be supported yet.
Are mods/multiplayer/SA:MP supported?
It depends. Some mods that modify game content/assets like models and textures may work properly. Other mods that load custom code or patch existing functions will likely not work yet. We are planning on expanding Saif in the future to support more of these. You can donate to help support the development of the project.
Are controllers supported?
Unfortunately not at the moment. We are planning on expanding Saif in the future to add controller support. You can donate to help support the development of the project.
Does Saif include the game?
No. Saif ships only its own application and no Rockstar content. You need your own legitimate, complete Windows install of GTA: San Andreas.
Is it free?
Yes. If you want to support development, you can donate.
How is this different from Wine or CrossOver?
Wine-based tools translate Windows, DirectX and x86 in generic layers. Saif is built for GTA:SA specifically: a custom ARM64 JIT for the CPU and a direct Metal renderer for graphics.
Something is broken. Where do I report it?
Open an issue on GitHub.

Setup guide

Please follow the steps below to setup the Saif runtime on your Mac.

  1. Get your game files Since Saif does not come shipped with the game files, you will need to provide them yourself. The most reliable way is to copy the full GTA: San Andreas folder from a legitimate Windows install onto your Mac (e.g. /Users/john/gta-sa). This game folder should contain gta_sa.exe.

    We always recommend obtaining a legitimate, original copy of the game.
  2. Download SaifGrab the latest release of the Saif runtime and drag Saif.app to Applications.
  3. Choose your game folderOpen Saif, click to select the GTA folder.
  4. Launch & playPress Launch Game to start playing.
