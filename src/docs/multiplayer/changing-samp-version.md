---
title: Changing SAMP version
description: How to change SAMP version in the Saif multiplayer launcher.
---

By default, Saif uses the latest SAMP version (`0.3.7-R5`) to connect to servers. It is recommended to always stick to the latest SAMP version, since Saif was only properly tested on this version.

If you still wish to change the SAMP version, you can do so at your own risk.

## Changing version (experimental)
1. Select the gear (settings) icon in the bottom right in the Saif multiplayer launcher.
2. All available SAMP versions are displayed in the pop-up.
3. Select a different version to automatically download and switch to it.
> **Note:** these versions are experimental and untested - use at your own discretion.
