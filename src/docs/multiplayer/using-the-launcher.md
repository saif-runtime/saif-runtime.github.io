This page explains the basic features of the Saif multiplayer launcher.

## Browsing servers
Many community servers are automatically shown in the multiplayer launcher. Scroll down to browse the list and find your desired server.

![Browsing servers in the multiplayer launcher](/assets/docs/browse-servers.png)

## Setting nickname
Set your nickname in the top right input field. This nickname will be used when joining community servers.

![Input field to set SAMP nickname](/assets/docs/set-nickname.png)

## Connecting to a server
Select the desired server you wish to connect to. Right-click -> "Connect" or use the connect button in the toolbar.

The game will be automatically launched and connect you to the server.

## Favorite servers
To easily find your often played servers, you can add them to your favorites. Right-click a server -> "Add to favorites", or use the star icon in the toolbar.

![Saving favorite servers](/assets/docs/favorite-servers.png)

## Adding a server manually
If a server does not show up in the server browser, or you want to join a private or local server, you can add it to the launcher manually. Tap the "+" icon to add a new server, enter the address and port and you are done.  

![Adding a server manually through IP and port](/assets/docs/add-server-manually.png)
