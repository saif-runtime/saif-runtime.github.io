Welcome to the Saif Runtime documentation page. Saif is a purpose-built runtime that plays your own copy of GTA: San Andreas on Apple Silicon. No need to install Wine, CrossOver, virtual machines, or other paid software.

Pages to get started with:
- [Setup guide](/docs/setup)
- [Showcase](/docs/showcase/)
- [How it works](/docs/how-it-works/)
