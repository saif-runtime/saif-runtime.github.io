Follow the steps below to set up the Saif runtime on your Mac.

## System requirements

| Requirement | Details                                                                                                                                                                   |
|-------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Mac         | Apple Silicon (M1 or newer). Intel Macs are unfortunately not supported.                                                                                                  |
| macOS       | macOS 13 Ventura or later                                                                                                                                                 |
| Game        | Saif only supports **GTA: San Andreas v1.0 US** (`gta_sa.exe`, 14,383,616 bytes). Other versions (Steam, Rockstar Launcher, Definitive Edition, v1.01) are not supported. |

## 1. Download Saif runtime
Download the latest version of Saif runtime on the [official website](https://saif-runtime.github.io/). 

Drag the Saif application to your Applications directory manually.

![Dragging Saif app to applications](/assets/docs/drag-to-applications.png)

## 2. Get your game files

Since Saif does not come shipped with the game files, you will need to provide them yourself. The most reliable way is to copy the full GTA: San Andreas folder from a legitimate Windows install onto your Mac (e.g. `/Users/john/gta-sa`). This game folder should contain `gta_sa.exe`.

We always recommend obtaining a legitimate, original copy of the game.

![Finder window showing a gtasa folder with gta_sa.exe](/assets/docs/game-files.png)

## 3. Choose your game folder

Open Saif, click "Choose..." to select the folder where your GTA SA install is on your Mac.

![The Saif launcher window with a game folder selected and a Launch Game button](/assets/docs/saif-preview.png)

## 4. Launch & play

If all was done correctly, you are ready to start playing.

![GTA: San Andreas main menu running in a macOS window](/assets/docs/game-running.png)
